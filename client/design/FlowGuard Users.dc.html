tenant isolation

Every user belongs to exactly one organization and sees only that organization's operations.

A user in Khalifa Bin Salman Port cannot see Gulf Aerial Survey's operations, and vice versa. This is enforced in the data layer — every query is scoped by organizationId before it reaches the UI — not by hiding rows on the client.
